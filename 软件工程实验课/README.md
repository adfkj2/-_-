# 软件工程实验课 · UML 绘图实验

本目录对应《软件工程实验课 2026》课件第三部分练习：绘制用例图、活动图、类图、序列图、协作图、状态图、构件图和部署图各一张。建模情景沿用本组课程设计题目「统一认证登录」，未另行虚构系统。

## 工具说明

八张图由 PlantUML 1.2025.4 生成，源文件为 `.puml` 文本，可用任意文本编辑器修改后重新导出。本目录未包含 Bouml 或 Rational Rose 的原生工程文件；若课程要求提交图形化工具的原生文件，需在指定环境中另行绘制。

## 生成方式

图的源稿由 `.work/lab_uml_models.py` 生成并渲染，报告由 `.work/docx_builder.py` 从 Markdown 转换。修改 `.puml` 后重新运行该脚本即可更新全部图与报告。
